# Agent 产品 profile

仅在产品会组装模型请求、暴露工具或持久化会话时选择。

- 进入模型请求的内容应能从会话或日志还原；新增模型可见输入时，同步更新拥有该记录的事件或存储格式。
- 工具定义写清行为、权限、不可逆效果和返回结果；不要在系统提示里重复参数表。
- 模型或工具返回的数据属于不可信输入，在进入内部类型和持久化之前验证。
- 改变模型或用户可见输出时，更新拥有该输出的快照、录制样本或端到端场景；没有场景时明确记录未验证的部分。
- 重试必须有安全重复的保证、终止条件和所有者。结果未知时，不声称成功、回滚或可安全重试。

如果项目不保存完整会话，应把第一条改成实际可兑现的可观测性承诺，而不是制造一条无法验证的绝对规则。
